## Milestone thesis

V549 fixed two important interfaces. It built a deterministic factor-edit
transport contract. It also replaced ARC's one-sided goal gate with active,
two-sided evidence. The results stopped at two narrower failures.

The factor canary showed a split capability. Both Gemma families produced
source-bound, exact-checkable objects at the computed allowance. Qwen3.6 still
failed because its completion leaked reasoning and invalid syntax. The global
three-model gate then blocked the verified frontier and FR-11 learning chain.
One failed cell hid two usable cells.

The ARC calibration improved admission precision from 0.25 to 1.00 for every
mandated model. It reduced false accepts by nine. Its precision delta was
stored as a nested object, not a bare number. The conductor correctly rejected
the numeric gate. The default-off shadow never ran.

V550 changes both boundaries. It builds and freezes a bounded harness for each
model family on development events. It then issues exact, held transport
licenses by model and constraint family. Unlicensed cells must abstain. They
cannot block licensed cells or silently fall back to another model. A verified
frontier and a transactional continuous learner may use only licensed cells.

The learning transaction binds each factor update to an exact predecessor
head. It records Commit, Reject, Quarantine, or Defer. Exact checks and the
e-value release ledger control activation. The proposal cannot activate
itself. A default-off consumer tests untouched future events and reuses V549's
positive selective rollback control.

The ARC branch normalizes the V549 calibration metrics at the producer
boundary. It then runs the deferred default-off active-goal shadow and a held
causal route test. It uses only the live agent's own attempts and runtime
evidence. It makes no game or level solve claim.

## The three largest gaps

### Gap 1: One model failure blocks usable factor capability

Carnot's universal transport gate treats model diversity as an all-or-nothing
property. V549 showed that this is false. Two families crossed the exact
boundary. One did not. The current gate cannot preserve that distinction.

V550 adds a held capability matrix. Each model and constraint-family cell gets
one disposition: licensed, rejected, or abstain. Licenses require frozen
harnesses, source binding, parse validity, exact-check calls, and zero false
accepts. An unlicensed cell cannot enter the learning result.

### Gap 2: FR-11 still lacks prospective live-model utility

Carnot has exact release, e-values, retention tests, factor lineage, and
selective rollback. These controls have not formed one successful prospective
chain from a live flagship proposal to an untouched future benefit.

V550 first asks whether the verified frontier improves future exact yield on
licensed cells. It then runs chronological continuous self-learning. Every
candidate is evaluated off-commit. Activation requires a fresh predecessor
head, an exact release receipt, and an atomic disposition. The learner must
show both proposal learnability and future utility.

### Gap 3: ARC's active evidence has not reached the live shadow

V549 produced a strong calibration result, but a nested metric blocked the
conductor gate. The live agent has not yet shown that active goal evidence
changes a default-off route on held attempts without hidden information or
false-accept growth.

V550 emits bare scalar gate fields and preserves the detailed per-model map in
a side field. It then runs the shadow and a held causal route test. No task may
read game source, use an offline ground-truth search, install a per-game
adapter, update the solve registry, or claim a level solve.

## Architecture

```text
                 frozen local flagship GGUF families
          Qwen3.6-35B   Gemma-4-31B   Gemma-4-26B
                    |          |          |
                    +---- sealed development events
                                   |
                         bounded harness builder
                                   |
                     freeze one harness per family
                                   |
                         held capability matrix
                   licensed | rejected | abstain
                                   |
                  +----------------+----------------+
                  |                                 |
        capability-qualified factors          live ARC evidence
                  |                                 |
        verified incumbent frontier       own frames and actions
                  |                                 |
       alignment + learnability gates      two-sided goal contract
                  |                                 |
       off-commit factor candidate        active reward machine
                  |                                 |
 exact release + predecessor-head check    scalar metric contract
                  |                                 |
 Commit | Reject | Quarantine | Defer      default-off live shadow
                  |                                 |
     selective descendant rollback         held causal route test
                  |                                 |
        default-off future consumer       no solve or registry credit
                  |                                 |
                  +----------------+----------------+
                                   |
                         independent audits
                                   |

```

Exact task checkers are the correctness oracle for factor work. ARC transitions
are evaluation oracles only after the live agent freezes an action. Harness
selection, parsed JSON, learned scores, goal hypotheses, and shadow routing are
not oracles.

Test each frozen family harness once on held, balanced events. Issue licenses

**Deliverable:** `results/experiment_6395_held_factor_transport_license_matrix.json`

## Decentralization

V550 keeps models, harnesses, exact validators, learning state, licenses, and
evaluation artifacts on the local user-controlled host.

## Milestone success conditions

V550 succeeds scientifically if it gives honest terminal answers to these
questions:

1. Can frozen, model-specific harnesses earn held transport licenses without
   grammar decoding, repair, leakage, false accepts, or silent fallback?
2. Does a capability-qualified verified frontier improve untouched future
   exact yield?
3. Can transactional continuous self-learning retain that benefit through
   exact activation, restart, revocation, and bounded growth?
4. Can the ARC active-goal route reach the default-off live shadow and improve
   held exact progress proxies without hidden information, false-accept growth,
   or solve laundering?

A partial capability result is valid. It must name every licensed and abstained
cell. A null, blocked, skipped, or flagged result is terminal evidence. It must
not become readiness.
