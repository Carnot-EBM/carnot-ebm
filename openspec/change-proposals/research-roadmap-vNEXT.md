## Thesis

Milestone `.517` ended earlier than its planning document anticipated. The activated roadmap
contained four tasks, Exp5796-Exp5799, not the thirteen-task range reserved by its transition.
Exp5796 completed the `.516` transition, Exp5797 found no accepted post-marker source delta, and
Exp5798 classified the older 1,080-row answer-channel evidence. Exp5799 then exercised all three
mandated GGUF families on twelve independent canary units, but only Gemma 4 31B qualified. More
importantly, adversarial verification CRITICAL-flagged the artifact because
`parser_failure_rate == truncation_rate == 0.775`; its aggregate and GPU-resume provenance are
quarantined and cannot support a milestone claim.

Milestone `.518` treats that flag as an evidence defect to repair, not as permission to rerun the
same mechanism. It first writes a companion audit without sanitizing Exp5799, then implements the
materially different split-budget transport suggested by recent work on the coupling tax: reasoning
and finalization receive independent budgets and receipts. A sealed finite candidate environment
may constrain syntax, but exact parsers and solvers remain semantic authority. The changed canary
runs all three mandated local models and permanently retires this transport lane if it reaches the
same not-ready verdict.

Only a clean three-family canary may emit a prospective chronological constraint stream. That
stream feeds the milestone's required continuous-self-learning chain: quarantined typed skills,
immutable future-batch validation, commit or rollback, multiple changes, restart equivalence,
bounded memory, composition, boundary awareness, and leave-one-family/surface transfer. GGUF
weights never change.

The independent ARC branch repairs the Exp5791 bootstrap order and tests a narrower live-path
hypothesis: three immutable single-shot world models can be admitted by the existing Exp5790
contract, selected using agent-owned calibration transitions, and improve held-out E3 behavior.
There is no public-game solve target, source inspection, offline ground-truth BFS, per-game adapter,
or iterative hypothesis patching. A backend-neutral bounded update/lookup kernel then preserves the
hardware path without repeating unchanged board probes or making a speed, energy, or 10x claim.

The milestone makes three falsifiable claims:

1. Independently budgeted reasoning and finalization can provide an auditable, exact-parseable
   channel for all three mandated local SOTA GGUF families; otherwise the lane is retired.
2. Frozen-model typed memory can improve a sealed future suffix through multiple distribution
   changes without protected-fact distortion, old-prefix regression, unbounded growth, or failed
   rollback.
3. Immutable agent-induced world models can be selected using only live-path calibration evidence
   and improve held-out E3 policy behavior with a positive paired lower bound.

## The three biggest gaps to the PRD vision

### Gap 1 — FR-12 has exact validators but no trustworthy family-portable result channel

The verifier cannot act when a reasoning model never emits its finite answer, and the existing
canary aggregate is quarantined. Carnot lacks an independently defined event taxonomy, reconciled
GPU/runtime provenance, separate reasoning/final budgets, replayable per-row receipts, and a clean
all-family qualification. This gap blocks every downstream claim based on model-produced labels.

### Gap 2 — FR-11 continuous self-learning has no prospective durability evidence

Carnot has exact typed-constraint machinery and earlier positive synthetic lifecycle results, but no
clean prospective three-family stream has reached the learning stage. It has not demonstrated
future-batch admission, stale-skill replacement, composition, justified abstention, multi-change
retention, memory retirement, restart equivalence, or OOD safety under frozen current SOTA models.

### Gap 3 — Learned state is neither live-policy-reachable nor hardware-portable

Exp5790's ARC admission contract exists, but Exp5791 blocked before model loading because outputs
were treated as preconditions. No immutable selector has influenced the scored E3 entrypoint on a
held-out split. Separately, NFR-01's 10x goal remains open after retirement of the allocation-free
software route. The attached boards need a small stable ABI and resource map before future
acceleration work, not another unchanged physical probe.

Reuse the sealed Exp5785 fixture and the exact selected Exp5813 transport. Run each mandated family
at N>=30 independent units per primary family/surface/SAT cell, checkpoint each row, and preserve

**Deliverables:**

### Exp5815 — Future-validated typed-skill learning A/B

Compare frozen state, contradiction-only feedback, and query-driven typed skills. Every proposal
uses chronological prefix evidence, stays quarantined, and is committed only if an immutable future
batch has a positive paired lower bound, exact old-prefix retention, zero unsafe propagation, and
hash-exact rollback. Separately score acquisition, temporal replacement, composition, implicit
relevance, and justified abstention. GGUF weights and validators stay frozen.

**Deliverable:** `results/experiment_5815_future_validated_constraint_skill_ab.json`

### Exp5816 — Multi-change endurance, retirement, and restart

Replay at least three preregistered distribution changes through the credited lifecycle. Measure
dynamic regret, delayed retention, interference, stale-rule retirement, memory growth under a fixed
cap, abstention, quarantine, rollback, and interruption/resume equivalence. This is the milestone's
continuous-self-learning durability experiment.

**Deliverable:** `results/experiment_5816_constraint_skill_endurance.json`

### Exp5817 — Leave-one-family/surface OOD audit

Hold out generator family, constraint family, and proof-preserving surface axes. Compare reset,
frozen, transferred, and explicitly retired skill states. Separate useful composition and transfer
from model-identity shortcuts, leakage, and unsafe propagation. No shadow integration or production
answer-path wiring is allowed.

**Deliverable:** `results/experiment_5817_constraint_skill_ood_audit.json`
