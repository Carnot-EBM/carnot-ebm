## Three biggest gaps to the PRD vision

1. **Independent useful decisions, FR-06/12.** Existing scalar, additive and
   interaction heads have no qualified useful gain. Fit a small radial energy
   head on new source groups. Compare typed costs and calibration with matched
   scalar, linear, additive and equivalent logistic controls.
2. **Learning that improves later decisions, FR-11.** Projected parameter
   changes did not produce beneficial actions. Add local basis centers from
   released past errors. Compare against equal-size fixed-center learning,
   the frozen head and the earlier projected update mechanism. Audit retention.
3. **Useful complete-service deployment, FR-05/08, NFR-01.** Host cache behavior
   is measured, but useful decisions and full acquisition costs remain open.
   Measure the added memory work through a real Rust binding. Retain each
   device's actual scope and a complete cost boundary.

A learned compatibility energy is an estimate, not ground truth for incomplete
extraction. This milestone can support bounded source-decision evidence and a
conditional learning trajectory. It cannot establish general lifelong learning.
All tasks retain `generalized_learning_benefit_score=0`. Unknown model pretraining
exposure and unknown historical access remain explicit limitations.

Labels live in evaluator-owned files. Capture sees only complete public source

labels stay sealed until final heads and predictions are committed.

## Phase 1 — Qualify inputs and the new mechanism (Exp8083–8085)

**Exp8083** binds all fourteen tasks and preserves terminal V699 evidence.
It reuses the repaired authority reader. It authenticates historical inputs
without requiring historical scientific success. Private tests cover activation,
missing files, altered prompts, gate types and full-contract digest changes.

**Exp8084** ingests the selected papers and freezes the cohort and methods.
Use official RAGTruth training-split public fields. Exclude all known prior fit,
tune, evaluation, stream and retention sources by IDs and normalized hashes.
Also exclude near-duplicate source clusters using normalized five-token shingles
with Jaccard similarity at least .8. Record the compared inventory and unknown
coverage. Do not promise absence of unknown prior exposure.

Choose the lowest stable response ID per source without inspecting labels.
Sort groups by SHA256 of `V700` plus normalized source bytes. Allocate fit128,
tune64, evaluation192, stream256 and retention128: **768 source groups**.
Freeze selection before annotation access. Never replace a selected source after
seeing class, parsing, quality or model outcomes. Insufficient groups block only
the dependent data branches. Keep kernel, ARC and hardware work independently runnable.

**Exp8085** builds the bounded radial basis and durable center dictionary.
Use 64 seeded numerical fixture systems and independent reference calculations.
Check gradients, probability parity, typed-action parity, source identity, memory
limits and recovery. The acceptance result is fixture-only circular-positive.
Each phase includes a runnable prototype, private CLI validation and adversarial
mutation controls. No new implementation is marked complete by this plan.
