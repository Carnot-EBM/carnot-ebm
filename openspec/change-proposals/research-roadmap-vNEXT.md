# Carnot Research Roadmap vNEXT: Prospective Exact Energy and Guarded Harness Learning

**Created:** 2026-08-21
**Milestone:** 2026.08.558
**Status:** Planned
**Supersedes:** milestone 2026.08.557
**Experiments:** Exp6480 through Exp6492
**Primary question:** Can exact constraint energy improve fresh local-SOTA decisions and support guarded continuous learning without taking release authority from the exact checker?

## Executive decision

V558 moves one positive exact-energy result onto a new prospective local-SOTA
stream. It also moves the Exp6479 factor cache from interface readiness to a
guarded chronological study. The ARC branch remains separate. It tests whether
the current energy ranks live action prefixes by measured progress before it
changes the policy.

The milestone does not reopen the Exp6463 corpus. Exp6476 retired that lineage
because its held labels and membership did not have immutable pre-inference
proof. V558 creates a new contract and commits labels and membership before any
model process starts.

The milestone keeps one authority rule:

    local GGUF or memory proposes
              |
              v
       energy ranks or routes
              |
              v
        exact checker decides
              |
              v
       release, write, or veto

A learned score, scalar energy, cache hit, ARC heuristic, or language model may
not release an answer or admit a persistent write by itself.

## The three largest PRD gaps

### Gap 1: Exact energy has not transferred to fresh local-SOTA outputs

The PRD calls for a model-agnostic verification and repair pipeline. Exp6478
shows that exact energy can select the right member of a finite candidate set.
It does not show that the effect survives real outputs from the three mandated
GGUF families. The only recent SOTA corpus lineage is invalid for held claims.

V558 closes the measurement gap with:

- immutable labels and split membership before inference;
- raw output persistence before parsing or scoring;
- all three mandated local GGUF families;
- first, shuffled, and equal-budget controls;
- exact final outcomes and harmful-flip rows;
- no model or energy release authority.

### Gap 2: Continuous self-learning is wired but not yet measured as guarded harness evolution

The PRD and research program require continuous self-learning. Exp6479 supplies
the default-off cache interface. Earlier CSL tasks establish exact veto,
rollback, restart, and unique-event controls. They do not measure the production
factor-cache state as a guarded harness on a fresh prospective stream.

Recent work sharpens the protocol. Harness Continual Learning
(arXiv:2608.19013) separates update proposal from guarded commitment.
Phantom Gains (arXiv:2608.20290) requires a measured frozen null for transition
claims. The cache-policy study (arXiv:2608.20280) also warns that nominal cache
hits are not necessarily valid reuse.

V558 therefore requires:

- a frozen replicate null for acquisition, forgetting, and harmful flips;
- exact write admission before persistent state changes;
- candidate, quarantine, commit, rollback, and restart receipts;
- current-gain, historical-retention, and validity checks;
- exact applicability before a cache hit counts;
- bounded LFU, LRU, and control policies;
- an independent event-level audit.

### Gap 3: ARC has a safe shield but no decision-metric alignment result

The ARC safety shield is ready, but the project has not shown that its energy
orders candidate action prefixes by real progress. A decodable state does not
imply a useful planning metric. Decision-Metric Alignment
(arXiv:2608.18746) makes this distinction explicit.

V558 first measures rank agreement on frozen live-path traces. A live policy A/B
runs only if the energy clears the alignment gate. The task is mechanism-level
generalization. It does not target a named game, does not use a hand adapter,
and does not claim a game or level solve.

that supersedes the local exact stack. Extropic has no authenticated Carnot
hardware or API path. Logical Intelligence still exposes no reproducible local
Kona runner.

## Model policy

Exp6483 is the only task that must generate new candidate answers. It must call
cached_sota_pair() and resolve all three headline model families:

- unsloth/Qwen3.6-35B-A3B-GGUF;
- unsloth/gemma-4-31B-it-GGUF;
- unsloth/gemma-4-26B-A4B-it-GGUF.

Legacy Qwen3.5-0.8B and gemma-4-E4B-it may run only as labeled CPU smoke
controls. They cannot provide a headline row, satisfy an all-family gate, or
replace a missing mandated model. If a required GGUF or authenticated GPU path
is absent, Exp6483 must emit a blocked precondition artifact before model load.

No other task needs a new LLM call. It must replay Exp6483 raw bytes or use
deterministic exact and ARC logic. This keeps generator variance out of causal
comparisons.

## Acceptance criteria

The milestone is complete when:

1. All 13 task IDs have terminal artifacts or explicit blocked artifacts.
2. The Exp6463 lineage is not used as held evidence.
3. Any new LLM task includes at least one mandated SOTA GGUF. Exp6483 includes
   all three.
4. Every comparative claim has per-unit rows and row-derived aggregates.
5. Exp6487 executes a chronological continuous self-learning protocol.
6. Every persistent cache write has exact pre-admission evidence.
7. Every CSL transition claim clears a measured frozen null.
8. ARC work uses the reachable live path, includes registry precheck, records
   solve_provenance, and makes no targeted solve claim.
9. No learned signal becomes release authority.
10. No hardware claim is made without authenticated execution evidence.
11. Focused tests, spec coverage, row-consistency lint, adversarial verification,
    and applicable E2E checks are recorded.
12. OpenSpec, traceability, status, and changelog are reconciled without editing
    public results or the conductor.

## Decentralization implications

The milestone uses local open-weight GGUF models, local exact solvers, and local
event ledgers. It does not require a hosted judge, proprietary verifier, remote
memory service, or unavailable accelerator. Raw outputs and exact decisions
remain replayable on operator-controlled hardware.

The architecture also narrows trust. A model can propose. A cache can remember.
An energy can rank. Only a local exact checker can admit a write or release a
decision. This separation keeps the useful adaptive layer replaceable and
auditable without centralizing authority in one model provider or one hardware
vendor.
