# Research Roadmap vNEXT: Exact-State Refinement and Revocable Learning

**Milestone:** `2026.08.542`
**Date:** 2026-08-10
**Experiments:** Exp6284-Exp6296
**Phases:** 4
**Primary requirements:** FR7, FR11, FR12
**North-star constraint:** ARC-AGI-3 live-agent progress without hidden-source or offline-solve credit

## Milestone thesis

V541 built an exact ASP energy compiler. It also exposed three honest limits.
The flagship model benchmark was not clean enough to promote. The certified
dual cache was safe but too abstaining to be useful. The ARC mechanic router
was ready in its artifact but failed the duration evidence rule.

V542 tests one coherent architecture response. A local flagship model may
provide partial atom evidence. Carnot then refines a complete state against an
exact ASP energy. A transactional memory may retain only verified atomic
repairs. That memory must revoke stale precedents and show transfer beyond
exact replay. The ARC route receives a matched causal test, not a solve claim.

The exact ASP solver is an oracle in this milestone. Cold exact completion is
always a control. A repaired answer alone is not evidence that the model or the
energy path added value.

## The three largest gaps to the PRD vision

### Gap 1: exact constraints do not yet refine ordinary model state

FR12 requires deterministic constraint verification. Phase 3 also requires
global state revision. V541 verifies full candidate assignments after text
generation. It does not yet turn incomplete model evidence into an editable
configuration.

V542 adds a fail-closed partial-atom adapter. It then compares continuous
energy refinement, exact discrete completion, and cold exact completion under
matched budgets.

### Gap 2: continuous energy reasoning is not tied to exact semantics

FR7 and the Phase 3 vision require iterative state improvement. Carnot has
discrete exact energies and earlier generic Ising relaxations. It lacks a
bounded continuous relaxation whose value at every binary vertex is proven to
match the current ASP energy.

V542 builds the multilinear relaxation of the bounded discrete energy. It
checks every vertex. It reports fractional stationary points, rounding harm,
and cold-start controls. This is a small semantic bridge, not a learned Kona
replica or diffusion-model claim.

### Gap 3: continuous self-learning has no safe useful live path

FR11 requires retained knowledge, forward transfer, rollback, and no harmful
forgetting. V541's dual cache was safe but not useful. Its downstream
chronological and consumer tasks never became eligible.

V542 changes the mechanism. It uses keyed precedent revocation from TEPA and
evidence-filtered atomic repair items from MIRA. It uses the Crystallization
evaluation split to separate exact replay from future transfer. Model weights
remain frozen.

## Claim and retirement boundaries

- The exact ASP solver is an oracle. Every artifact must say so.
- Full repair accuracy is not a model-value result. Cold exact completion is a
  required control.
- The V541 dual-cache mechanism must not be rerun unchanged.
- The V541 mode-jump treatment must not be extended or renamed.
- KAN training, external generated-text scorers, finite-ID output transport,
  and per-game ARC adapters remain out of scope.
- No ARC hidden source, outer-loop ground-truth search, offline solve, public
  level solve claim, or registry update is allowed.
- No task may change model weights.
- Downstream tasks must skip before the agent call when a structured gate
  fails.

## Milestone success criteria

The milestone succeeds operationally if all exact artifacts are terminal or
mechanically skipped and the capstone preserves their true states.

The energy branch promotes only if the live benchmark shows value beyond cold
exact completion under a matched budget. The self-learning branch promotes
only if non-replay transfer is positive, unsafe advice is zero, retention is
non-negative, and rollback is exact. The ARC branch promotes only if the
matched canary and held-out audit improve the live proposal path without
baseline harm.

Null results are valid. A null result must close the branch instead of causing
an unchanged rerun.
