## Why now

Four prior attempts at a "Safety/Jailbreak KAN Classifier" exist in the
research log. None have a result JSON; all read "partial — script and tests
created, needs extended runtime." The pattern is a rubber-stamp failure mode
we just fixed elsewhere in the conductor (see commits `c2d96d1`, `86cbda0d`).

Meanwhile, three operational prerequisites landed in the last 2–3 weeks:
1. `cached_sota_pair()` resolves GGUF weights for SOTA teachers without the
   runtime having to know paths at experiment-author time.
2. The conductor's doc-reconciliation prompt now requires explicit
   `honest_verdict` mapping rather than "✅ Complete" on any experiment with
   `status: partial`.
3. The zombie-cascade fix (pytest.skip for experiment_623) unblocked the
   pattern of gating a whole module behind `apply_env_autofix`.

These three together make it realistic to land a working prompt-injection
classifier in one experiment instead of four partials.

## The core design

Reuse the KAN tier that already ships (`python/carnot/models/kan.py` +
`ComplianceEnergyChecker`). Change only the training corpus and the feature
encoder:

| Layer | Reused from | New |
|---|---|---|
| KAN forward pass | `kan.py` (unchanged) | – |
| Energy head | `compliance_checker.py` pattern | – |
| Feature encoder | – | `encode_prompt_injection(text)` — token n-grams + delimiter-pattern counts + role-keyword counts |
| Training corpus | – | 2000 (benign, inject) pairs distilled from `gpt-oss-safeguard-20b` |
| Honest-verdict mapping | – | 5 verdict strings per REQ-SAFE-009 |

Low energy = benign. High energy = injection. Thresholdable at deploy time.
Composes with the rest of the energy budget in `VerifyRepairPipeline`.

## Why this isn't "just call the teacher model"

1. **Cost / latency.** `gpt-oss-safeguard-20b` at Q4_K_M is ~12 GB and 500 ms
   per prompt on a single GPU. 2.3 K-param KAN is < 5 ms on one CPU core.
   For the VerifyRepairPipeline's per-request budget this matters by orders
   of magnitude.
2. **Hardware portability.** The KAN energy landscape compiles to the same
   Ising / FPGA / D-Wave backends as the rest of our EBM stack. Transformer
   safety models don't.
3. **Interpretability.** KAN spline control points are directly readable by
   an auditor, just as with `ComplianceEnergyChecker`. Transformer attention
   isn't.
4. **Compositional energy.** The pipeline already sums energies from other
   EBM checks. A calibrated scalar from the injection checker joins that sum.
   A transformer boolean does not.

## Corpus construction

**Benign (1000):**
- 500 GSM8K train split prompts (math reasoning).
- 500 HumanEval prompts (code reasoning).

Both are already in the research corpus via other experiments. No new
downloads.

**Injection (1000):**
- 500 JailbreakBench prompts (public, Apache 2.0).
- 300 AdvBench prompts (public, MIT).
- 200 synthetically generated by running the teacher against OWASP LLM-01
  category seeds with a controlled mutation process (see
  `scripts/jailbreak_mutations.py` — to be created).

Balance is exact (1000 / 1000) so AUROC is a clean metric.

## Execution plan

Deferred into a single experiment (Exp 652). Phases (wall-clock budget 90
min total, hard-stopped by `ExperimentTimeoutWatchdog`):

1. **Preflight (2 min).** Verify `gpt-oss-safeguard-20b` Q4_K_M is in the
   local cache. If absent, emit
   `honest_verdict: "blocked_on_dependency"` with the download command and
   exit 0. This is the fast-fail path.
2. **Corpus build (40 min).** Teacher inference over 2,000 prompts. Cache
   teacher outputs keyed by `(model_hash, prompt_hash)` so a re-run skips
   this phase.
3. **KAN training (20 min).** Adam + contrastive loss. Early-stop on
   held-out AUROC plateau. Emit training curve to
   `results/experiment_652_training_curve.json`.
4. **Held-out evaluation (5 min).** Compute AUROC on the 400-example test
   split. Map to `honest_verdict` per REQ-SAFE-009.
5. **Latency check (3 min).** 1,000 cold-cache CPU calls; assert median
   < 5 ms. Failure does not abort — just annotates the result.
6. **Result JSON emit (1 min).** Full schema per `REQUIRED_RESULT_FIELDS`
   from `experiment_template.py`, including `honest_verdict`, `reason`,
   `classifier_auroc`, `train_time_s`, `median_inference_ms`.

## Why this finally closes the thread

- Single experiment, single result JSON, single honest verdict — no more
  partial-forever state.
- Fast-fail preflight means "blocked on dependency" is reported in 2 min
  rather than the experiment looking like it ran for 90 min and failed
  opaquely.
- The verdict-string enum forces the conductor reconciliation step to map
  `status != success` to a documentation update, not a rubber-stamp.

## What's explicitly out of scope

- **Foundation-model integration.** Don't wire the checker into the
  VerifyRepairPipeline's default energy budget in this experiment. That's
  a follow-up (Exp 653 proposed) once calibration is done.
- **Red-teaming.** No adversarial prompt generation against the student
  beyond the 200 synthetic injections. Dedicated red-team experiments
  come later.
- **Multilingual coverage.** English-only in this phase. Non-English
  jailbreaks are a known gap and a later experiment.
