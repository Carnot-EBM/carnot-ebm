- Three zombie processes (PIDs 145715/254433/289150) ran continuously for 4.4+ additional hours through .35, accumulating ~23.8GB VRAM on GPU 0 at 0% utilization. The session-start health check fired once but could not prevent mid-session accumulation from failed GPU-required experiments.

- JEPA AUC regressed from 0.667 to 0.400 due to insufficient data quality validation before the scale experiment.
- The five non-adopted throughput improvements (conductor dedup, partial-result handoff, inference batching, retro budget, thermal gate) account for the bulk of the estimated 33% savings.

## The 3 Biggest Gaps Between Current State and PRD Vision

### Gap 1: No credible live verify-repair improvement (FR-12, Goal #2)
Three consecutive milestones (.33/.34/.35) ended without a confirmed 100q+ live verify-repair improvement number. Exp 451 showed +5pp at 50q but the result file was absent at retro time. Exps 464, 467, 468 were all deferred_to_gpu in .35 due to zombie VRAM saturation. This is the most critical gap — without a credible positive number, Carnot cannot claim to solve the hallucination problem it was built to solve.

**Root cause to fix first:** GPU VRAM is not checked before each GPU-required experiment. A mid-session zombie check that gates every GPU experiment (not just the session start) would have prevented all four deferred_to_gpu experiments in .35.

### Gap 2: JEPA Tier 3 AUC regression (FR-11)
JEPA AUC dropped from 0.667 to 0.400 in Exp 472. The self-learning loop (FR-11) requires the JEPA predictor to improve monotonically as real CoT data accumulates. A regression of this magnitude indicates data quality failure, not architectural failure. The fix: quality-gate real CoT pairs before training (require labeling_rate >= 0.3 and arithmetic coverage >= 0.3), augment with high-quality synthetic pairs generated by the EBM itself, and validate on a held-out set before committing the retrained model.

### Gap 3: GPU 1 completely idle (hardware waste, blocks dual-model benchmarks)
GPU 1 (24GB RTX 3090) has been at 0% utilization for at least 3 consecutive milestones. DualGPURunner exists in experiment_template.py but no live benchmark harness actually assigns models to cuda:1. Running both Gemma4-E4B-it (cuda:0) and Qwen3.5-0.8B (cuda:1) in parallel would reduce dual-model benchmark wall time by ~50%, enabling more questions per session and wider statistical confidence intervals.

## Phase Descriptions

### Phase 1: Fix Root Cause (Exps 474–475)

The first two experiments must ship before any GPU experiment is scheduled. They address the root cause of all four deferred_to_gpu experiments in .35.

**Exp 474 — GPUVRAMGate**: A context manager that runs before EVERY GPU-required experiment (not just session start). It calls gpu_monitor.py to check free VRAM, kills zombie processes if free VRAM < threshold, waits up to 60 seconds for VRAM to free, and defers the experiment with honest_verdict='gpu_vram_insufficient' if the wait fails. This is the single highest-impact fix: it prevents mid-session zombie accumulation from blocking subsequent GPU experiments.

**Exp 475 — Conductor Dedup + Partial-Result Handoff**: Before executing experiment N, the conductor checks if results/experiment_N*.json already has a complete honest_verdict (not 'partial', 'blocked', 'deferred_to_gpu'). If complete, skip. PartialResultHandoff serializes ExperimentTemplate state to results/experiment_NNN_partial.json on SIGTERM/exception. The next session resumes from the checkpoint. Addresses the triple-re-verification pattern (Exp 447) and interrupted-run recovery overhead.

### Phase 2: Deferred Live Benchmarks (Exps 476–479)

All four experiments deferred in .35 due to zombie VRAM. Now unblocked by Exp 474 GPUVRAMGate.

**Exp 476 — Live 100q Precision**: RETRO-033 third attempt. Uses IntegratedExtractor (VeriCoT + VPRM + CRANE) with DualGPURunner. Target: confirm the +5pp Exp 451 result at 100q with Wilson 95% CI. Writes CoT pairs for Exp 477 JEPA retrain.

**Exp 477 — JEPA Quality-Gated Retrain**: RETRO-040 fix. Diagnoses the AUC regression (0.667→0.400). Loads all available real CoT pairs, filters by quality_score >= 0.3 (arithmetic coverage + labeling confidence). Generates EBM-guided synthetic augmentation pairs (not random). Retrains JEPA on quality-filtered corpus. Target: AUC > 0.700 on held-out set.

**Exp 478 — Live 200q VeriCoT+VPRM**: RETRO-038 second attempt. Runs 200 GSM8K questions per model with full extraction stack. Target: statistically-significant improvement (lower bound of Wilson 95% CI > 0). This is the headline credibility experiment for Phase 1 completion.

**Exp 479 — GSM-Symbolic Adversarial**: RETRO-039 first live attempt. Apple's GSM-Symbolic (arXiv 2410.05229) tests adversarial robustness. Carnot's thesis: verify-repair improvement should be LARGER on adversarial variants than standard GSM8K because Ising verifies arithmetic independently of irrelevant context. This is the key credibility-establishing result.

### Phase 3: Throughput Hardening + New Research (Exps 480–483)

**Exp 480 — Harness DualGPURunner**: Wire cuda:1 into all dual-model benchmark harnesses (Exps 439/464/467/468 class). Implement DualGPUHarness that patches any harness loading two models to use cuda:0/cuda:1 respectively. Conductor pre-check: flag any harness with 2+ models that doesn't reference cuda:1.

**Exp 481 — Inference Batching Enforcement**: BatchedInferenceRunner must be used in all benchmark harnesses. Implement InferenceBatchingAudit that reads harness scripts and flags sequential loops over questions without BatchedInferenceRunner. Enforce batch_size=8 for GSM8K, batch_size=4 for HumanEval.

**Exp 482 — ThinkProbeV2 Live GPU**: RETRO-036/042 second attempt. Now with GPUVRAMGate pre-check. Uses GemmaTransformersLoader. Target: complete 50 questions within 65-min budget.

**Exp 483 — KAEM Profile at n_vars>200**: RETRO-031 closure. Profile KAEM vs ParallelIsingSampler at n_vars={100, 200, 500, 1000}. Find the crossover point where KAEM exceeds 5x speedup threshold. KAEM showed only 1.29x at n_vars<=100 in Exp 447; theory predicts >10x for n_vars>200 where MCMC mixing time dominates.

### Phase 4: New Research (Exps 484–485)

**Exp 484 — Neural Uncertainty Principle Probe** (arXiv 2603.19562): The Neural Uncertainty Principle frames hallucination as an under-constrained continuation problem — a mathematical perspective directly compatible with Carnot's constraint-satisfaction formulation. This experiment implements NUPProbe: given a partial LLM response, compute the entropy of the continuation distribution as a proxy for constraint violation likelihood. If the probe AUC > 0.70 on predicting violations from live CoT data (Exps 442/476 pairs), it becomes Tier 0c in the verification pipeline cascade, providing a fast (no-LLM, pure-math) pre-filter.

**Exp 485 — PPSEBM Real-Data Validation**: RETRO-043 closure. Exp 470 showed PPSEBM achieved partition_isolation_score > 0.8 on synthetic data but the benchmark was synthetic-only. This experiment runs PPSEBM on the real violation patterns from Exps 456 (constraint_addition.py) and 476 (live CoT pairs). Target: session_fp_rate on real data < lsebmcl_fp_rate (0.0 was already achieved on synthetic — the real question is whether partition isolation holds on natural arithmetic/code/logic interleaving).

## Self-Learning Advancement

This milestone advances FR-11 (Autonomous Self-Learning Loop) via:

- **Tier 3 (JEPA)**: Exp 477 retrains JEPA on quality-gated real CoT pairs, targeting AUC recovery to >0.700. Quality gating introduces a data quality self-assessment loop: the EBM evaluates its own training data before committing to a retrain.
- **Tier 2 (PPSEBM)**: Exp 485 validates PPSEBM (Progressive Parameter Selection) on real violation patterns from live GPU runs, testing whether domain-partitioned learning holds on natural interleaving of arithmetic/code/logic sessions.
- **Tier 1 (Online weights)**: Exp 476 and 478 both produce new CoT pairs that flow into the FOVER annotation pipeline, keeping the Tier 1 per-constraint-precision tracker fed with real data.
