# Token Activations (Carnot)

Per-token hidden-state activations collected from several open-weight LLMs
generating answers to factual QA prompts, with sequence-level
correctness labels projected to the token level. This is the training
corpus for Carnot's `per-token-ebm-*` model family -- energy-based
classifiers that score token-level model **confidence** (not factual
correctness; see "Honest scope" below).

- **License:** Apache 2.0
- **Source repo:** [github.com/Carnot-EBM/carnot-ebm](https://github.com/Carnot-EBM/carnot-ebm)
- **Generated by:** `scripts/collect_token_activations.py` (and
  `collect_token_activations_large.py` for the larger subset)
- **Used by:** all sixteen `Carnot-EBM/per-token-ebm-*` model repos

## Honest scope (read this first)

Carnot's exp184 / exp203 follow-ups showed empirically that EBMs trained
on these activations detect **how confident the source LLM was when
generating a span**, not **whether the span is factually correct**.
Confident hallucinations score with low (correct-looking) energy;
hedging-but-correct answers score with high (hallucination-looking)
energy. This dataset is therefore appropriate for:

- Research on activation-space structure of confidence vs. correctness
- Training calibration probes that operate over hidden states
- Baselining "naive activation EBM" against the more honest signal of
  the [Carnot framework's](https://github.com/Carnot-EBM/carnot-ebm)
  output-side constraint verifiers

It is **not** an appropriate training set for a production hallucination
detector. The shipped Carnot pipeline (`pip install carnot-ebm`) uses
constraint extraction + energy verification of *outputs*, not
activation-space probes.

## Schema

Each `.safetensors` file packs four parallel arrays of length N
(tokens), where N varies per file:

| Tensor          | Dtype   | Shape   | Meaning                                                   |
|-----------------|---------|---------|-----------------------------------------------------------|
| `token_ids`     | int32   | `[N]`   | Vocabulary indices of the generated tokens                |
| `activations`   | float32 | `[N,D]` | Last-layer hidden-state vectors (D depends on source model)|
| `labels`        | int32   | `[N]`   | `1` = source answer matched ground truth, `0` = hallucinated |
| `question_ids`  | int32   | `[N]`   | Index of the prompt that produced this token              |

Sequence-level labels are projected to all tokens in the generated answer
-- every token of a correct answer is labelled `1`, every token of a
hallucinated answer is labelled `0`. This is the right granularity for
training a per-token energy model.

Per-model hidden dimension (`D`):

| File suffix                  | Source model                              | D     |
|------------------------------|-------------------------------------------|-------|
| `_qwen35_nothink`            | Qwen/Qwen3.5-0.8B (thinking disabled)     | 1024  |
| `_qwen35-2b_nothink`         | Qwen/Qwen3.5-2B (thinking disabled)       | 2048  |
| `_qwen35-27b_nothink`        | Qwen/Qwen3.5-27B-A4B (thinking disabled)  | 5120  |
| `_qwen35_merged`             | Combined Qwen3.5 sweep (varies; see file) | 1024  |
| `_qa_qwen35`                 | Qwen3.5-0.8B on QA-only subset            | 1024  |
| `_lfm25-350m_nothink`        | LiquidAI/LFM2.5-350M                      | 1024  |
| `_lfm25-12b_nothink`         | LiquidAI/LFM2.5-1.2B-Instruct             | 2048  |
| `_bonsai-17b_nothink`        | prism-ml/Bonsai-1.7B-unpacked             | 2048  |
| `_large`                     | QA-only superset, mixed source models     | mixed |
| `_combined`                  | factual QA + TruthfulQA portion           | mixed |

## Generation procedure

For each `(question, expected_answer_substring)` pair, the source LLM
generates a completion. The completion is deemed correct if
`expected_answer_substring` appears (case-insensitive) in the decoded
output. For each token in the generated answer, the script records:

1. The token's vocabulary index.
2. The last-layer hidden-state vector at that token's position.
3. The sequence-level correctness label, projected to that token.
4. The question id.

The factual-QA component covers arithmetic, geography, historical
dates, scientific facts, and similar single-fact prompts. The
TruthfulQA component (in `_combined`) uses the public TruthfulQA
benchmark prompts to capture a different failure mode (memorized
falsehoods).

## Loading

```python
from huggingface_hub import hf_hub_download
import safetensors.numpy as st

path = hf_hub_download(
    repo_id="Carnot-EBM/token-activations",
    filename="token_activations_qa_qwen35.safetensors",
    repo_type="dataset",
)
data = st.load_file(path)
print(data["activations"].shape)  # (N, 1024)
print(data["labels"][:10])        # [1 1 1 0 0 0 1 1 0 1]
```

## Training the matching EBM

Each per-model subset corresponds to one of the
[`Carnot-EBM/per-token-ebm-*`](https://huggingface.co/Carnot-EBM) models.
The training script is `scripts/experiment_per_token_ebm.py` in the
[source repo](https://github.com/Carnot-EBM/carnot-ebm).

```bash
git clone https://github.com/Carnot-EBM/carnot-ebm
cd carnot-ebm
pip install -e .
# Pre-download the dataset file you want, place under data/, then:
python scripts/experiment_per_token_ebm.py --source-model qwen35-0.8b
```

## Limitations

- **Activation-confidence, not correctness.** See "Honest scope" above.
- **Small QA corpus.** The factual-QA portion covers ~1300 prompts; the
  TruthfulQA portion adds the standard 817 prompts. Sample sizes per
  source model vary; check the loaded file's `labels.shape` before
  drawing statistical claims.
- **Sequence-level label projected to tokens.** A correct answer that
  contains a hallucinated word still has all its tokens labelled `1`;
  this introduces label noise at the per-token level. The EBMs trained
  on this data inherit that noise.
- **No held-out TruthfulQA split documented in the data itself.**
  `question_ids >= 10000` indicate TruthfulQA provenance in
  `_combined`; consumers should split by `question_id` rather than by
  row index to avoid leakage.
