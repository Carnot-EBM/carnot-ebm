# V664 service placement

Experiment 7613 measures the durable local recalibration request. It separates
update arithmetic from journal write, fsync, reload, acknowledgment, and the
combined caller remainder. The remainder can include IPC, scheduling, state
reads, prediction, and client work. The report does not call it pure IPC.

The local learner updates nine spline knots. This is a small CPU task. The
whole request also requires durable file and directory synchronization. A
kernel-only time does not describe that service. The measured arithmetic share
therefore supports only an Amdahl upper bound. It does not measure FPGA,
spintronic, thermodynamic, or other accelerator latency.

The hardware wishlist remains useful for larger verified workloads. Extropic
Z1T is future-access and compatibility context. The September 22 spintronic
lead is research context. Neither option has an equal-semantics durable request
measurement here. No purchase follows from the spline kernel alone.

KV260 keeps its graduated FPGA-fabric scope. Future work uses `ssh kria` and
keeps `k_max<=5`; it does not use host block devices. PolarFire keeps its
graduated Linux CPU-dispatch scope, while FPGA sampling remains unmeasured.
GateMate still needs a dated cable, port, power, board, JTAG, or DirtyJTAG
change receipt before another execution task. Experiment 7613 performs no
probe or flash.

The existing public client stays opt-in. The experiment changes no empirical
weights and no production default. It does not claim useful learning, a 10x
gate, a PyO3 crossing, or E2E-003.
